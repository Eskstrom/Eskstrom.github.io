Make costs understandable

Address, dimensions, weight, handling, pickup, and speed choices lead to an itemized estimate. People can edit the review without losing unrelated selections.

Treat recovery as part of the task

Existing version-5 checks cover required fields, a price change from $19.99 to $29.99 when speed changes, payment decline and retry, and a start-over confirmation that preserves the order if dismissed. These are synthetic demo prices and interaction checks.

Be precise about the handoff

The receipt describes a concept handoff without promising email, postage, or live tracking. Keyboard, narrow-screen, and physical-kiosk accessibility checks remain to be completed.
