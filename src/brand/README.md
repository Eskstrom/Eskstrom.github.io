# Orbital Sentinel — original approved artwork

`orbital-sentinel-original.png` is an unchanged copy of the first generated concept approved by the owner. It is retained as the source of truth, not traced or redrawn.

The site build embeds the original PNG in SVG viewports for the header/footer mark and favicon, framing only the large central face. Presentation labels and sample icons lie outside the viewport. The source pixels, colors, and details remain intact. Browser scaling necessarily reduces visible detail at small sizes.

The generated `docs/assets/sentinel.svg` and `docs/assets/favicon.svg` override the earlier simplified assets during each build. No additional decorative placements are added.
